# Cấp 0 Tours — Tour engine + 3 Chặng-2 tours Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** Build a reusable spotlight/tour engine + the 3 Cấp-0 Chặng-2 product tours (Bảng điện ②, Bản tin ③, 6 người chơi ④), wiring them into the existing Journey checklist so tasks 2/3/4 become completable — which makes Cấp 0's 6/6 + graduation reachable (today they're hardcoded `locked` → Cấp 0 is an unfinishable dead-end).

**Architecture:** FE-only (dashboard/). Backend is untouched — `PATCH /cap0/task` + `Cap0Progress.task_2/3/4_done_at` columns + `cap0Visibility.orderBook = graduated || task2Done` already exist. Completing a tour calls the existing `useCompleteTask(taskNo)`. Order-book unlock happens automatically once task ② is done.

**Tech Stack:** React 19 + Arco + Tailwind v4 + TanStack Query + Vitest/RTL.

## Global Constraints
- **Spotlight chuẩn (IQX, dùng chung):** overlay `rgba(10,12,20,.52)` (or the tour docs' `rgba(6,8,14,.72)` — pick one, apply consistently), ô sáng viền brand `rgb(var(--primary-6))`/`#4f8ff7` 3px + outline trắng 2px, bo 12px, đệm 9px; tooltip nền trắng chữ đen, max-width 380px, đệm 16-18px, bo 14px; ưu tiên vị trí dưới→phải→trái, clamp trong màn; chuyển bước 2 pha (fade→scroll→reposition→fade) 350-400ms; cờ `busy` chặn double-click.
- **Tooltip layout:** `ĐIỂM x/N` counter + tiêu đề đậm + thân + `Tiếp theo →` / `← Quay lại` (ẩn bước 1) / `Bỏ qua tour` (cuối = `Hoàn thành ✓`).
- **Skip = hoàn thành:** bấm "Bỏ qua tour" vẫn set task done (spec).
- **Ngôn ngữ VN**, số en-US (app-wide convention). No confetti/childish.
- **Gating:** tours run inside Cấp 0 (`isCap0Active`), launched from Journey "Làm ngay →". A tour already done (`task_N_done_at` set) shows the row as `done`, not re-run (but re-runnable via the row if desired — optional).
- **Delta-only:** do NOT fork the trading terminal — add `data-tour-id` attributes to existing elements; the tour reads them. Do NOT touch backend.
- Analytics: emit `tour_<name>_{start,step_view,skip,complete}` via the app's existing analytics hook if one exists; else a no-op stub + TODO.

```ts
// tourTypes.ts
export interface TourStep {
  targetId?: string        // matches a data-tour-id="..." in the DOM
  targetSelector?: string  // fallback CSS selector
  centered?: boolean       // no hole, tooltip centered (concept cards)
  tang?: string            // pill label e.g. "XEM MỘT MÃ"
  title: string
  body: string             // may contain minimal inline markup; render as text
  placement?: "below" | "right" | "left" | "auto"
}
export interface TourConfig { name: string; steps: TourStep[] }
// useTour.ts
export function useTour(config: TourConfig, opts: {
  onComplete: () => void            // called on Hoàn thành ✓ OR Bỏ qua
  onStepView?: (i: number) => void
  onStart?: () => void
  onSkip?: (i: number) => void
}): { active: boolean; start: () => void; stop: () => void; ...internal }
// TourOverlay.tsx — <TourOverlay config controller /> renders overlay+hole+tooltip via portal when active
```
